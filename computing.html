Computing the pictures

Level: IntermediateBuilds on The Mandelbrot set and External rays & angles

Every picture in this atlas is a computation: a grid of sample points, a finite number of steps, and arithmetic that rounds. This chapter explains the methods behind the pictures, what each one proves and what it only suggests, and how far a computer can be trusted at all.

A picture is a computation

A picture of the Mandelbrot set colors a grid of pixels. Each pixel stands for one parameter c, usually the one at its center, and the program follows the orbit of 0 under z2 + c for at most a fixed number of steps, the iteration budget. Three things can then go wrong:

  • Sampling. The set has filaments far thinner than a pixel. A pixel whose center misses them is drawn as outside, even though the set passes through it.
  • The budget. Near parabolic parameters, orbits escape only after very many steps, so a pixel that has not escaped yet may still be outside. Milnor gives an extreme example from a dynamical plane: for z ↦ z + z4, a point 10−3 from the parabolic fixed point 0 needs about 3·108 steps to move away from it (Milnor’s lectures, Appendix G).
  • Rounding. A computer stores about 16 significant digits and rounds at every step; near repelling cycles errors grow geometrically, as the orbits chapter shows.

One verdict is solid: an orbit that leaves the disk of radius 2 escapes for certain, by the escape proof, so a colored pixel shows that its sample point is outside the set, up to rounding. A dark pixel only says that the orbit had not escaped yet. The rest of this chapter is about getting more out of the same computation, and about the few methods that turn pictures into proofs.

Escape time, done carefully

The escape time of a pixel is the first step n at which |zn| exceeds the escape radius R; any R ≥ 2 proves escape for the Mandelbrot set, and R ≥ max(2, |c|) for a Julia set. Coloring by n gives the bands of the classic pictures. Most of the work goes into the pixels that never escape, since each of them uses up the whole budget. Two tricks save almost all of it.

Exact tests for the two largest components. A parameter c = x + iy lies in the main cardioid exactly when q(q + x − 1/4) < y2/4, with q = (x − 1/4)2 + y2, and in the period-two disk exactly when |c + 1| < 1/4. Both follow from the multiplier formulas of the periodicity chapter, and together they cover most of the interior in a picture of the whole set. No equally simple test exists for the other components.

Periodicity checking. An orbit that settles into a cycle never escapes, so a program can stop once it detects the cycle. The documentation of the program Fractint credits Mark Peterson with the idea. A cheap way to detect a cycle is to keep one point and compare later points with it, renewing the kept point at steps 8, 16, 32, …, a scheme due to Richard Brent (Brent, 1980). The atlas’s renderer stops only when an orbit returns exactly to a kept value. That is safe: a sequence of computed numbers that repeats exactly repeats forever and never escapes. Stopping when the orbit merely comes close to a kept point is faster, but it can misjudge orbits that escape very slowly.

From counts to the potential

Escape time jumps by whole steps, which gives the bands. A continuous version comes from looking at how fast an orbit leaves. Far from 0, z2 + c is almost z2, so log|z| doubles at each step and log2 log|z| goes up by 1, an observation credited to Earl Hinrichs (Linas Vepstas, 1997). Subtracting it from the step count gives the smooth count

ν = n + 1 − log2 log|zn|,

which hardly depends on when the program stops. It is the escape potential of the rays chapter in disguise: as R grows, ν approaches 2 − log2 GM(c), so the curves on which ν is constant are equipotentials, and smooth coloring is a picture of the potential. The escape radius matters here. In a test at 20,000 random parameters outside the set with |c| ≤ 2, ν differed from its limit typically by about 0.05 and at worst by 1.7 with R = 2, by at most 2·10−3 with R = 16, and by at most 2·10−7 with R = 1000. With R = 2 the seams between bands remain visible; with R = 1000 they disappear.

Reading external angles from a picture

A picture can also show the external angle θ of each parameter outside the set. Color each escaping pixel by the sign of the imaginary part of zn when it escapes. Since φc(zn) = ΦM(c)2n−1 and φc(z) ≈ z far out, the argument of zn is about 2n−1 times that of ΦM(c). So, except very close to the edges of the cells described below, Im zn > 0 when the n-th binary digit of θ is 0, and Im zn < 0 when it is 1. This is binary decomposition; the name goes back to Peitgen and Richter’s The Beauty of Fractals (1986), and Peitgen and Saupe’s The Science of Fractal Images (1988) gives it for the Mandelbrot set as the algorithm BDM/M: the picture splits into cells whose edges follow equipotentials and the parameter rays at angles k/2n. It needs a large escape radius, so that φc(z) is really close to z. For points on the rays at 1/3, 1/7, 5/12, 1/5 and 3/11, traced as in the rays chapter, escaping past R = 106 and reading the signs of four further iterates gave the correct digits every time. The figure’s pixel inspector reads the digits of the angle in this way.

Rays themselves are drawn by Newton’s method, as the rays chapter describes. Tomoki Kawahira wrote up the method, crediting the principle to Mitsuhiro Shishikura (Kawahira, 2009). One pitfall is easy to fall into: the angles must be doubled exactly, as fractions, because a floating-point angle loses one binary digit with every doubling.

How far is a pixel from the set?

Thin filaments are the hardest part to draw: a pixel may contain a piece of the set while its center misses it. A distance estimate tells how close a sample point is to the set. Along with the orbit, compute its derivative with respect to c,

z′n+1 = 2znz′n + 1, z′0 = 0,

and when the orbit escapes, form

b = 2 |zn| log|zn| / |z′n|.

As the potential tends to 0, the true distance d from c to the Mandelbrot set satisfies b/4 ≲ d ≤ b. The upper bound comes from Schwarz’s lemma and the lower bound from the Koebe one-quarter theorem, both applied to the conformal map ΦM; for connected Julia sets the same holds with z′0 = 1 and without the + 1 (a modern proof: Brouillette, Parisé and Rochon, 2019). Both ends occur. Near the tip, at c = −2.0001, the estimate is four times the true distance 10−4; near a smooth piece of boundary it is about twice the distance, as for the Julia set of c = 0, the unit circle, at z = 1.001.

A program that draws every pixel with b smaller than the pixel as part of the set shows the filaments that point sampling misses. The idea is due to John Milnor and William Thurston; the algorithm DEM/M is in The Science of Fractal Images, where Yuval Fisher’s appendix also covers the outside of the set with disks that miss it, using the Koebe bound. Milnor remarked that pictures missing the filaments are what led Mandelbrot to believe at first that his set was disconnected (Milnor’s lectures, Appendix G). Inside a hyperbolic component a similar estimate comes from the multiplier map, which maps the component conformally onto the unit disk.

Julia sets backwards

A Julia set can also be drawn without testing any pixel. Every point of the Julia set has its preimages ±√(z − c) in it (two of them, except at z = c), and backward orbits are attracted to the Julia set. So start at a repelling fixed point, such as β = 1/2 + √(1/4 − c), choose one of the two preimages at random again and again, and plot the points: this is inverse iteration. It works because of Hans Brolin’s theorem: the 2n preimages of almost any point after n steps spread out over the Julia set according to a fixed distribution, the harmonic measure (Brolin, 1965); a single random backward orbit does the same, as Jane Hawkins and Michael Taylor proved in 2003 (stated and cited by Stankewitz and Sumi).

Harmonic measure is very uneven. It is the distribution in which a random particle coming in from far away would hit the set, and the deep fjords of a Julia set are almost never reached. As Milnor put it, following Mandelbrot, inverse iteration “yields an excellent picture of the outer parts” of the Julia set “but shows very little detail in the inner parts” (Milnor’s lectures, Appendix G). Measured on a 720 × 540 grid, as in the figure below, a million random preimages come within one pixel of about 88% of the boundary pixels of Douady’s rabbit, and of only about 62% for the golden-mean Siegel disk, whose edge is hard to reach from outside.

One case can be worked out exactly. At c = −2 the Julia set is the segment [−2, 2], and the chaos chapter writes its points as x = 2 cos 2πθ, so that the map doubles θ. Harmonic measure is then the image of the uniform distribution of θ, which has density 1/(π√(4 − x2)) on [−2, 2], the arcsine law: it piles up at the two ends and is thinnest in the middle. A million random backward steps z ↦ ±√(z + 2) follow it closely, with about 23% of the points within 0.5 of each end and only about 8% in each half-unit next to 0. It is also the measure of maximal entropy, and averaging log|2x|, the logarithm of the stretching factor, against it gives exactly log 2: the errors that double in the chaos chapter.

The modified inverse iteration follows all preimages in a tree but stops following a branch once its pixel has been hit often enough. It already appears in Peitgen and Richter’s The Beauty of Fractals (1986) and is studied in Dietmar Saupe’s paper on efficient computation of Julia sets (Saupe, 1987); on the same grid it reaches 99% to 100% of the boundary pixels in about a hundredth of a second. A practical warning came up in the same test: with a poor random number generator, one whose low bits repeat after 217 steps, the backward orbit locked onto a single cycle, and ten million points showed nothing that a million did not.

Finding special parameters

The centers of hyperbolic components and the Misiurewicz points are roots of polynomials, which Newton’s method finds quickly. A center of period p solves zp(c) = 0, where zp is the orbit of 0, and the derivative z′p comes from the same recurrence as for the distance estimate. Starting from −0.1 + 0.7i, five Newton steps give the rabbit’s center −0.1225611669 + 0.7448617666i to full double precision. A Misiurewicz point solves zk+p(c) = zk(c); dividing out the factors that belong to smaller preperiods or periods keeps Newton’s method from converging to them.

Finding all centers of one period is harder, because zp(c) = 0 has 2p−1 roots, the centers of all periods dividing p (see counting components), and Newton’s method has fractal basins. John Hubbard, Dierk Schleicher and Scott Sutherland showed how to choose a set of starting points from which Newton’s method finds every root of a polynomial (Hubbard, Schleicher and Sutherland, 2001). With this approach Schleicher and Robin Stoll found all 220 = 1,048,576 centers of period dividing 21 and certified the result: disjoint disks around the computed values each provably contain exactly one center (Schleicher and Stoll, 2017). The closest two are only 2.7·10−11 apart, so close that for a few pairs the simple disks overlapped and a sharper estimate was needed to separate them.

Zooming deeper than the hardware allows

Ordinary computer numbers, IEEE double precision, have 53 binary digits, about 16 decimal ones. Near |c| ≈ 1 neighboring numbers are about 2.2·10−16 apart, so once a window is so narrow that neighboring pixels are only a few such steps apart, the picture shows rounding instead of the set. The zoom viewer stops at a width of about 6·10−13, a magnification of about 5·1012. In a test around c = i, escape counts computed in double precision already disagreed with a 60-digit computation for 2 of 432 pixels at width 10−11 and for 112 of 432 at width 10−13.

Programs for deep zooms go much further, to magnifications of 101000 and beyond. Computing every pixel with thousands of digits would take days per picture; instead they compute one reference orbit with many digits and every pixel as a small difference from it in ordinary numbers, a method called perturbation. The chapter on deep zooms explains it, with the glitches it caused, the rebasing that cured them and the shortcuts that skip millions of iterations.

Pictures you can trust

A picture can be made into a proof. Instead of following one parameter per pixel, follow all parameters of a small disk around the pixel at once: enclose zn, for every c in the disk, in a disk of numbers, and round every operation outward, so that the true values stay inside. This is ball arithmetic, a form of interval arithmetic. Each pixel then gets one of three verdicts:

  • proved outside: the enclosing disk lies beyond radius 2 at some step, so every parameter in the pixel escapes;
  • proved inside: the pixel lies in the main cardioid or the period-two disk, or some iterate maps a small disk around an attracting cycle into itself for every parameter in the pixel, and the orbit of 0 falls into that disk;
  • undecided: neither could be shown.

Pixels proved inside are inside the Mandelbrot set, and every pixel that meets the set is proved inside or undecided. So a picture whose window contains the whole set, as the figure’s does, brackets the area of the set: the area of the pixels proved inside is a lower bound, and adding the undecided ones gives an upper bound. On a grid of 768 × 576 pixels the figure below proves that the area lies between 1.377 and 2.272. Such bounds are far weaker than the best estimate, about 1.5066 from counting pixels (a statistical estimate, not a bound), but they are proved; area, dimension and famous numbers compares the known bounds. The figure’s program allows for every rounding error, by outward rounding or by safety margins far larger than the errors, but it has not been formally verified. Geoffrey Irving has gone further: he proved in the proof assistant Lean that his program for an upper bound, including its interval arithmetic, is correct, and running it shows that the area is at most 1.826454 (Irving’s ray-render).

Can a computer draw the Mandelbrot set to any desired accuracy? Peter Hertling showed that it can if hyperbolic parameters are dense, an open problem (Hertling, 2005); without it the question is open. For Julia sets the answer is known to be no in some cases: Mark Braverman and Michael Yampolsky found quadratic Julia sets that no program can draw to arbitrary accuracy, all of them with Siegel disks (Braverman and Yampolsky, 2006), and later showed that this can happen even for a parameter that a program can compute (2008). Such parameters are rare: on the boundary of the main cardioid their angles form a set of measure zero. And of Cremer points, Milnor wrote: “As far as I know, no useful computer picture of such a point has ever been produced!” (Milnor’s lectures, Appendix G).

Key ideas

  • A pixel is a sample: escape beyond radius 2 is proved, “not escaped yet” is not, and thin filaments can fall between samples.
  • Exact tests for the cardioid and the period-two disk, and periodicity checking, save most of the work of drawing the interior.
  • The smooth count ν = n + 1 − log2 log|zn| is a picture of the escape potential, and the sign of Im zn reads the binary digits of the external angle, both with a large escape radius.
  • The distance estimate b bounds the distance to the set within a factor of 4 (Koebe), which reveals filaments; inverse iteration draws Julia sets but neglects their deep parts, which the modified method fills.
  • Deep zooms use perturbation around one high-precision orbit (see the chapter on deep zooms); ball arithmetic turns pictures into proofs, with three verdicts: outside, inside, undecided.

Check yourself

  1. Why does a dark pixel not prove that its parameter is in the Mandelbrot set?

    It only shows that the orbit of 0 did not leave the disk of radius 2 within the budget. It may leave later, as orbits near parabolic parameters do after very many steps; and the pixel’s center is only one of the parameters it stands for.

  2. Check the cardioid test at c = 0 and at c = 0.3.

    At c = 0: q = 1/16, and q(q − 1/4) = (1/16)(−3/16) < 0 = y2/4, so 0 is inside. At c = 0.3: q = 0.0025, and q(q + 0.05) = 0.00013 > 0, so 0.3 is not in the cardioid; it is in fact outside the set, beyond the cusp 1/4.

  3. If |zn| = 103 at the first step past R, by how much does log2 log|z| grow at the next step?

    The next value is about 106, and log 106 = 2 log 103, so log2 log|z| grows by log2 2 = 1. The step count n also grows by 1, so ν = n + 1 − log2 log|zn| hardly changes when the program stops one step later.

  4. With a large escape radius, a pixel escapes with Im zn < 0 at step n = 5. What does that say about its external angle?

    The fifth binary digit of θ is 1.

  5. The distance estimate at a point is b = 0.004. Between which values does the distance to the set lie?

    Between about b/4 = 0.001 and b = 0.004. The bounds hold in the limit of small potential, so they apply close to the set.

  6. Why does inverse iteration draw the outer parts of the rabbit well and its deep fjords badly?

    Its points are distributed by harmonic measure, the probability of hitting the set from far away, which is tiny in the fjords; a modified method that follows all preimages but prunes well-covered pixels reaches them.
