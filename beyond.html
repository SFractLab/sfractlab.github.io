Beyond z2 + c

Level: IntermediateBuilds on The Mandelbrot set and Minibrots & self-similarity

The quadratic family is the simplest family of maps with complicated dynamics, and an unusually well-behaved one. Change one ingredient, such as the degree, the arithmetic or the number of critical points, and some of its theorems survive while others fail. This chapter makes those changes one at a time. Halfway through, it reaches a theorem that explains why small copies of the Mandelbrot set turn up in almost every family of rational maps that depends holomorphically on a parameter.

What makes z2 + c special

Five properties of fc(z) = z2 + c carry most of the theory in this atlas.

  1. It is holomorphic in z. The map is complex-differentiable, so Montel’s theorem on normal families applies and divides the plane into the Fatou set and the Julia set (the Fatou set).
  2. It depends holomorphically on c. The multiplier of a cycle is then a holomorphic function of the parameter. It becomes a coordinate on each hyperbolic component (multiplier coordinates), and away from the boundary of M Julia sets deform without changing their type (where Julia sets change).
  3. It is a polynomial. Infinity is a superattracting fixed point, so Böttcher’s coordinate and external rays exist (Böttcher’s coordinate), and the bounded Fatou components are simply connected.
  4. It has a single critical point. The orbit of 0 decides whether the filled Julia set is connected or dust (the quadratic dichotomy), and since every quadratic polynomial becomes exactly one z2 + c after a change of coordinates, one complex parameter describes them all.
  5. Its degree is two. External angles double at each step (angle doubling), so the combinatorics of the Mandelbrot set is written in binary.

Each section below gives up one or more of these properties and reports what survives. The figure shows four of the families, each drawn like the Mandelbrot set: dark where the orbit of 0 has not escaped.

Higher degree: Multibrot sets

The closest relatives keep the single critical point and raise the degree: zd + c for a whole number d ≥ 2. Their Multibrot set Md is again the set of parameters for which the orbit of 0 stays bounded; M2 is the Mandelbrot set. Almost everything in the earlier chapters carries over. If |z| > max(2, |c|), then |zd + c| ≥ |z|d − |c| > |z|(|z|d−1 − 1), and the factor |z|d−1 − 1 is larger than 1, so the orbit escapes as in the escape proof for d = 2. The filled Julia set is connected when the orbit of 0 is bounded and a Cantor set when it escapes, for the same reason as in degree two. Each Md is connected, and the outside of Md is a conformal copy of the outside of the unit disk, so parameter rays are defined as for M (Eberlein, Mukherjee and Schleicher, introduction). Angles are now multiplied by d at each step, so expansions in base d replace binary ones, and the main landing theorems of the rays chapter hold: rays at periodic angles land at parabolic parameters, and rays at preperiodic angles at Misiurewicz parameters (their Theorem 1.1).

The first visible change is the symmetry. Let ω be a (d − 1)-th root of unity, so that ωd−1 = 1. Then ω−1((ωz)d + c) = zd + c/ω, so the maps for c and c/ω are the same map in rotated coordinates, and Md is unchanged by a rotation through 1/(d − 1) of a full turn. For d = 2 this rotation is trivial, which is why M has only the mirror symmetry of complex conjugation. M3 is symmetric under a half turn and M4 under a third of a turn, as the figure shows. The filled Julia sets have d-fold symmetry instead, because (ωz)d = zd when ωd = 1, just as the quadratic ones are symmetric under z ↦ −z.

The main component changes with it. A fixed point z of zd + c has c = z − zd and multiplier dzd−1, so the parameters with an attracting fixed point are the values c = z − zd with |z| < d−1/(d−1). For d = 2 this is the main cardioid. In general its boundary has d − 1 cusps, where the multiplier equals 1: there zd = z/d, so c = (1 − 1/d)z. For d = 3 the cusps are at ±2/(3√3) ≈ ±0.385.

Every hyperbolic component still has a multiplier map onto the unit disk, but it now covers the disk d − 1 times (Eberlein, Mukherjee and Schleicher, Theorem 4.5). A component of period greater than one therefore has one root, where two parameter rays land, and d − 2 further boundary points with multiplier 1, its co-roots, where one ray lands each; the main component has no root and d − 1 co-roots, its cusps (Theorem 1.1). The real axis meets Md in the interval from −21/(d−1) to (d − 1)d−d/(d−1) when d is even, which is [−2, 1/4] for d = 2, and in the interval between the two cusps ±(d − 1)d−d/(d−1) when d is odd (Baribeau and Ransford, who credit the odd case to Parisé and Rochon and the even case to Parisé, Ransford and Rochon). As d grows, Md approaches the closed unit disk (Boyd and Schulz, 2012).

The deep theorems carry over where they are known. Md is locally connected at every parameter that is at most finitely renormalizable and has only repelling cycles, which extends Yoccoz’s theorem to every degree (Avila, Kahn, Lyubich and Shen, 2009), and its boundary has Hausdorff dimension 2, since Shishikura’s theorem holds in every degree. Whether every Md is locally connected is open, as it is for M. Pictures of “z2.5 + c” and other non-integer powers belong to a different kind of map: a non-integer power needs a branch cut, along which it jumps, and the seams in such pictures come from that cut, not from the dynamics.

Reflecting the plane: the tricorn

Take the complex conjugate, z = x − iy for z = x + iy, before squaring: z ↦ z2 + c. The map still has degree two and the single critical point 0, but it reverses orientation instead of preserving it: it is antiholomorphic. The parameters for which the orbit of 0 stays bounded form the tricorn. Crowe, Hasson, Rippon and Strain-Clark studied it first, in 1989, as the “Mandelbar set” (Nonlinearity 2). John Milnor found it again in the parameter space of real cubic polynomials, as “a quite different three pointed configuration, which I will call a ‘tricorn’” (Remarks on iterated cubic maps, §4).

Two steps of the map make an ordinary holomorphic polynomial, (z2 + c)2 + c, so much of the dynamical theory survives: Fatou and Julia sets, the dichotomy between connected sets and dust, Böttcher’s coordinate and external rays. On the real axis the conjugation does nothing, so the tricorn and the Mandelbrot set have the same real slice, [−2, 1/4], and the same real dynamics. The rotation argument of the last section, now with ω3 = 1, gives the tricorn three-fold symmetry; for zd + c, whose connectedness locus is called a multicorn, the symmetry is (d + 1)-fold. A fixed point z attracts when the stretching factor 2|z| is less than 1, so the main component consists of the parameters c = z − z2 with |z| < 1/2. Its boundary is the deltoid c = eiθ/2 − e−2iθ/4, a curved triangle with cusps at distance 3/4 from 0, one of them at −3/4, and smooth where it crosses the real axis at 1/4, the cusp of M.

What fails is holomorphy in the parameter. The iterates mix c and c, so they depend on c only real-analytically, and “already the open mapping principle of the multiplier map fails”, as Hubbard and Schleicher put it. The consequences took nearly three decades to work out:

  • Shizuo Nakane proved in 1993 that the tricorn is connected, adapting Douady and Hubbard’s proof (Nakane).
  • Components of even period behave as for M. A component of odd period is bounded entirely by parabolic parameters: by three arcs of them meeting at three cusps (d + 1 of each for a multicorn), and at its bifurcations the period doubles along arcs of positive length, near both ends of each parabolic arc, instead of at single points (Mukherjee, Nakane and Schleicher).
  • Parameter rays at rational angles that accumulate on the boundaries of odd-period components of period greater than one do not land; they accumulate on arcs of positive length. The boundary also contains real-analytic arcs with nothing attached to them, so Misiurewicz parameters, which are dense in the boundary of M, are not dense in that of the tricorn (Inou and Mukherjee, 2016).
  • No multicorn is path connected (Hubbard and Schleicher, 2014), so none is locally connected: the opposite of what the MLC conjecture predicts for M.

Two critical points: cubic polynomials

A cubic polynomial has two critical points. After a change of coordinates every cubic can be written as z3 − 3a2z + b, with critical points ±a, so the family has two complex parameters. Its connectedness locus, the set of (a, b) for which both critical orbits stay bounded, lies in a space of four real dimensions, and pictures show two-dimensional slices of it. Bodil Branner and John Hubbard proved that it is compact and connected (Acta Mathematica, 1988).

The filled Julia set is still connected exactly when both critical orbits are bounded, and a Cantor set when both escape. In between, the dichotomy fails. When one critical orbit escapes and the other stays bounded, the Julia set is disconnected, but it need not be dust: some of its pieces can be distorted copies of connected quadratic Julia sets. Fatou expected that a Julia set could be a Cantor set only if every critical orbit escapes, and Hans Brolin found real cubics whose Cantor Julia set contains a critical point. Branner and Hubbard settled the cubic case: the Julia set is a Cantor set exactly when no component of the filled Julia set that contains a critical point is periodic. Their conjecture that this holds in every degree was proved independently by Weiyuan Qiu and Yongcheng Yin (arXiv) and by Oleg Kozlovski and Sebastian van Strien (Proc. London Math. Soc., 2009).

Milnor listed further differences in his remarks on cubic maps (§3): hyperbolic components come in four kinds instead of one, they are not organized in a tree, and the connectedness locus is not locally connected, as Pierre Lavaurs showed. The tricorn of the last section appears in one of its real slices, where Milnor found and named it.

Newton’s method and rational maps

The oldest question in the subject concerns a rational map. Newton’s method for a polynomial p replaces a guess z by N(z) = z − p(z)/p′(z), and in 1879 Arthur Cayley asked which starting points lead to which root (the history chapter). For a quadratic with two distinct roots the answer is simple: Newton’s map is conjugate to z ↦ z2 by a Möbius transformation, and the basins of the roots are the two half-planes on either side of the perpendicular bisector. For z2 + 1, for example, N(z) = (z − 1/z)/2, the upper half-plane is the basin of i, and the Julia set is the real axis together with ∞.

For z3 − 1, Newton’s map is N(z) = (2z3 + 1)/(3z2). A rational map of degree three has four critical points: here the three roots, which are superattracting fixed points, and 0, which N sends to ∞, a repelling fixed point. Every attracting or parabolic cycle of a rational map attracts a critical point, and the edge of a Siegel disk or Herman ring lies in the closure of an infinite critical orbit; here every critical orbit is finite, so the roots are the only attractors, and the Fatou set consists of their three basins. The boundary of the basin of an attracting cycle is the whole Julia set (Milnor’s lectures), so the three basins have one common boundary: every point on the edge of one basin is on the edge of all three.

Newton’s method can also fail on open sets. For p(z) = z3 − 2z + 2, Newton’s map sends 0 to 1 and 1 back to 0, and 0 is a critical point of N because p″(0) = 0, so the cycle 0 ↔ 1 is superattracting and a whole region of starting points never finds a root (Hubbard, Schleicher and Sutherland, 2001, Figure 1). Curtis McMullen proved in 1987 that for polynomials of degree four and more no purely iterative algorithm, a fixed rational map built from the coefficients and applied again and again, converges for almost every polynomial and almost every starting point; for cubics such algorithms exist, though Newton’s method is not one of them (McMullen, Annals of Mathematics, 1987). Newton’s method can still be made to find every root, from a well-chosen set of starting points (finding special parameters).

Newton’s maps are rational maps, quotients of polynomials, the maps for which Fatou and Julia built their theory. Some facts carry over from z2 + c unchanged: a rational map of degree d has 2d − 2 critical points, counted with multiplicity, and at most 2d − 2 cycles that are not repelling (Shishikura), and Sullivan’s theorem rules out wandering domains (the Fatou set). Others do not: infinity is an ordinary point, so there are no external rays in general.

Why the Mandelbrot set keeps coming back

In 1983 James Curry, Lucy Garnett and Dennis Sullivan looked at Newton’s method for the cubics pc(z) = (z − 1)(z2 + z + c) = z3 + (c − 1)z − c (Communications in Mathematical Physics 91). Besides the roots, Newton’s map has one more critical point, 0, where pc″ vanishes, and its orbit decides whether the method fails on an open set: if 0 is attracted to a cycle other than the roots, so is a whole region of starting points. Color each parameter c by the fate of the orbit of 0, and small dark Mandelbrot sets appear: the parameters where Newton’s method fails (Aspenberg and Roesch study the same family, in a parameter λ with c = 1/4 − λ2). At c = 1 the polynomial is z3 − 1.

Curtis McMullen showed that this is no accident (The Mandelbrot set is universal, 1997, published 2000). Take any family of rational maps of degree at least two that depends holomorphically on its parameters, and its bifurcation locus: the parameters near which the number of attracting cycles is not constant, or equivalently where the Julia set does not move continuously. For z2 + c it is the boundary of M (where Julia sets change). McMullen’s theorem says that the bifurcation locus is either empty or contains quasiconformal images of the boundary of a Multibrot set Md, that these copies are dense in it, and that for a generic family d = 2 (Theorem 1.1, Corollary 1.2 and Corollary 4.4). As a consequence, the bifurcation locus of every such family, if it is not empty, has full Hausdorff dimension: 2 for a family with one complex parameter, and twice the number of complex parameters in general, which extends Shishikura’s theorem (Corollaries 1.6 and 1.8).

The mechanism is the one behind minibrots (renormalization and straightening): near a suitable parameter, some iterate of the map behaves like a quadratic-like map on a small disk, and straightening turns the family of these maps into a copy of the quadratic family. Two limits are worth keeping in mind. The theorem needs holomorphic dependence on the parameter, so it says nothing about the tricorn or the Burning Ship. And it is a different statement from Feigenbaum’s universality, which concerns the scaling ratios of period doubling; both are called universality.

A zoo of rational Julia sets

Rational maps have Julia sets that no polynomial can have.

  • The whole sphere. For F(z) = (i/2)(z + 1/z), the critical points ±1 go to ±i, then to 0, then to ∞, a repelling fixed point. Every kind of Fatou component needs a critical orbit that is periodic or infinite, so F has none, and its Julia set is the entire Riemann sphere. F is a Lattès map, which comes from a linear map of a torus, as z2 − 2, the c = −2 example, comes from angle doubling on a circle, with the segment [−2, 2] as its Julia set (Milnor, On Lattès maps).
  • Carpets. The Julia set of a rational map can be homeomorphic to the Sierpiński carpet; Milnor and Tan Lei found the first example in 1992, and for z2 − 1/(16z2), in Devaney’s family z2 + λ/z2, the critical orbits reach the immediate basin of ∞ only at the third step (the critical points go to ±i/2, then to 0, then to ∞), and the Julia set is a carpet (Devaney, Fagella, Garijo and Jarque). A polynomial’s Julia set is never a carpet, because the basin of ∞ is a single Fatou component whose boundary is the whole Julia set.
  • Cantor sets of circles. In McMullen’s family zn + λ/zd, for instance z3 + λ/z3, the Julia set is a Cantor set of closed curves around 0 when λ ≠ 0 is small enough (Devaney, Look and Uminsky).
  • Herman rings. A Fatou component can be an annulus on which an iterate of the map rotates. Polynomials cannot have such rings (neutral cycles), and rational maps need degree at least three (Shishikura). They add a fourth kind of periodic component to the attracting basins, parabolic basins and Siegel disks of the Julia chapter.

Pictures without theorems

Some popular fractals look like relatives of the Mandelbrot set but stand outside its theory. The Burning Ship of Michael Michelitsch and Otto Rössler (1992) iterates z ↦ (|x| + i|y|)2 + c, where z = x + iy. Since (|x| + i|y|)2 = x2 − y2 + 2i|xy|, the map is z2 + c where xy ≥ 0 and z2 + c where xy < 0: a splice of the Mandelbrot map and the tricorn map along the axes, holomorphic in neither sense. Some easy facts survive. The escape radius max(2, |c|) still works, and for real c the orbit stays real and follows x2 + c, so the real slice is [−2, 1/4] once more. But there is no normal-family theory, no Böttcher coordinate and no external rays, and as far as we know nobody has proved or disproved that the Burning Ship set is connected.

Quaternions add two more imaginary units to the complex numbers, and Alan Norton rendered quaternion Julia sets in 1982 (SIGGRAPH ’82). The quaternion Mandelbrot set, however, is nothing new. A quaternion c = a + v, with real part a and imaginary part v, lies in a plane spanned by 1 and v that multiplies exactly like the complex numbers, and the orbit of 0 never leaves it. So c belongs to the quaternion Mandelbrot set exactly when a + |v|i belongs to M: the set is M spun around the real axis (Boily and Rochon, Theorem 5).

The Mandelbulb was found by Daniel White and Paul Nylander in 2007–2009: it raises points of space to a power by multiplying their spherical angles, and power 8 gives the best-known pictures (White’s page). It is not a three-dimensional Mandelbrot set in any mathematical sense. There is no number system in three dimensions that extends the complex numbers: by Frobenius’s theorem the only finite-dimensional associative division algebras over the reals are the real numbers, the complex numbers and the quaternions. And by Liouville’s theorem the only angle-preserving maps of space are Möbius transformations, so space has nothing like the holomorphic polynomials behind every theorem in this atlas. The “spherical product” behind it is not even associative (Boily and Rochon). Whether Mandelbulbs are connected is open, and little about them has been proved (Knill, 2023). A genuine dynamical theory in higher dimensions exists for quasiregular maps, built by Hinkkanen, Iwaniec, Martin, Mayer and others for uniformly quasiregular maps and extended to entire quasiregular maps by Bergweiler and Nicks, but its examples are not the Mandelbulb.

Entire functions

For the exponential family λez, infinity is an essential singularity instead of an attracting fixed point, so there are no Böttcher coordinates, and escape is no longer detected by a radius. Michał Misiurewicz proved in 1981 that the Julia set of ez is the whole plane, confirming a conjecture of Fatou (Misiurewicz). For 0 < λ < 1/e there is an attracting fixed point, and the Julia set is a Cantor bouquet: uncountably many disjoint curves, called hairs, running out to infinity (Devaney and Krych, 1984). Hairs play the role of external rays.

Wandering domains, impossible for rational maps, exist here: Irvine Noel Baker built the first entire function with one in 1976, and Michael Herman’s example z − 1 + e−z + 2πi pushes each basin of Newton’s method for ez − 1 into the next (Bergweiler’s survey, §4). Eremenko conjectured in 1989 that every component of the set of escaping points of a transcendental entire function is unbounded. Martí-Pete, Rempe and Waterman disproved this in 2025 (Journal of the AMS); for the important class of entire functions with bounded singular values it is proved for functions of finite order but open in general as of October 2026 (Rempe).

Neighboring worlds

Kleinian groups. The first picture of the Mandelbrot set was made by Brooks and Matelski while they studied groups of Möbius transformations (the history chapter). The connection runs deep. Sullivan proved that rational maps have no wandering domains by translating Ahlfors’s finiteness theorem for Kleinian groups into dynamics, and McMullen later laid out Sullivan’s dictionary between the two subjects: limit sets correspond to Julia sets, and Sullivan’s theorem that the limit set of a finitely generated Kleinian group carries no invariant line field corresponds to the conjecture that the Julia set of a rational map carries none unless the map is a Lattès map, a conjecture that would imply density of hyperbolicity (McMullen, The classification of conformal dynamical systems). Shaun Bullett and Luna Lomonaco proved that a family of holomorphic correspondences introduced by Bullett and Christopher Penrose, which mate quadratic maps with the modular group, has a connectedness locus homeomorphic to the parabolic Mandelbrot set, and hence, by a theorem of Petersen and Roesch, to M (arXiv).

Mating. Adrien Douady proposed gluing two filled Julia sets along their boundaries, matching the external ray at angle t of one with the ray at −t of the other, to obtain a rational map of degree two (Séminaire Bourbaki, 1982). For parameters with finite critical orbits, the mating exists exactly when the two parameters do not lie in complex-conjugate limbs of M (Tan Lei, Rees and Shishikura, as stated by Milnor). Milnor worked out a striking example: mating the dendrite z2 + c with c ≈ −0.228 + 1.115i with itself gives the Lattès map F above: two dendrites glued into the whole sphere (Pasting together Julia sets). Arnaud Chéritat’s mating movies show such gluings in motion.

Physics. In the Ising model on certain hierarchical lattices, renormalization acts on the temperature by a rational map, and the complex temperatures at which the partition function vanishes, the Fisher zeros, accumulate on the Julia set of that map (Derrida, De Seze and Itzykson, 1983; Bleher and Lyubich, 1991). Here a Julia set is the physical object itself. The logistic map and the period-doubling experiments of the chaos chapter are the real slice of the quadratic family, and so of the tricorn as well.

Key ideas

  • The theory of z2 + c rests on five properties: holomorphic in z and in c, a polynomial, one critical point, and degree two.
  • Multibrot sets zd + c keep almost everything: connectedness, the dichotomy, parameter rays and their landing theorems; their symmetry is (d − 1)-fold, and their main component has d − 1 cusps.
  • The tricorn shares the real slice of M and is connected, but depends on c only real-analytically: odd-period components are bounded by parabolic arcs, some rational rays do not land, and it is not path connected.
  • With two critical points the dichotomy fails: a cubic Julia set can be disconnected without being dust.
  • McMullen’s theorem: in every holomorphic family of rational maps, quasiconformal copies of the boundary of a Multibrot set, generically the Mandelbrot set’s, are dense in the bifurcation locus.
  • The Burning Ship, quaternion sets and the Mandelbulb are escape-time pictures without the complex-analytic theory; the quaternion Mandelbrot set is M spun around the real axis.

Check yourself

  1. Show that M3 is symmetric under c ↦ −c.

    Conjugate by z ↦ −z: −((−z)3 + c) = z3 − c. So z3 + c and z3 − c are the same map in coordinates turned by a half turn, and the orbit of 0 of one is bounded exactly when that of the other is. This is the rotation argument with d − 1 = 2 and ω = −1.

  2. Find the centers of period dividing 2 of z3 + c. How many components of period 2 does M3 have?

    The orbit of 0 is 0, c, c3 + c, so the centers solve c3 + c = c(c2 + 1) = 0: c = 0, the center of the main component, and c = ±i. So there are two components of period 2, centered at i and −i, above and below the main component in the figure. In general zd + c has dn−1 centers of period dividing n.

  3. Why do the tricorn and the Mandelbrot set have the same real slice?

    For real c, the orbit of 0 under either map stays real, and for real z the conjugate z equals z. So the two maps produce the same orbit, and the orbit is bounded for exactly the same real c: those in [−2, 1/4].

  4. For p(z) = z3 − 2z + 2, check that Newton’s map swaps 0 and 1, and explain why starting points near 0 never reach a root.

    p′(z) = 3z2 − 2. Then N(0) = 0 − 2/(−2) = 1 and N(1) = 1 − 1/1 = 0. The derivative of Newton’s map is N′ = pp″/(p′)2, and p″(0) = 0, so N′(0) = 0: the cycle 0 ↔ 1 has multiplier 0 and attracts every starting point close enough to 0 or 1.

  5. Which of these matings exist: the basilica (c = −1) with the rabbit, the rabbit with its mirror image, and the basilica with itself?

    The basilica lies in the 1/2-limb and the rabbit in the 1/3-limb, which are not complex conjugates, so that mating exists. The mirror image of the rabbit lies in the 2/3-limb, the conjugate of the 1/3-limb, so the rabbit cannot be mated with it. The 1/2-limb is its own conjugate, so the basilica cannot be mated with itself.

  6. Why does the Burning Ship have no external rays, although its escape test is the same as for M?

    External rays come from Böttcher’s coordinate, which needs a map that is holomorphic near infinity. The Burning Ship map is z2 + c in two quadrants and z2 + c in the other two, so it is neither holomorphic nor antiholomorphic, and no such coordinate exists. The escape test only needs |(|x| + i|y|)2| = |z|2.
