The mathematics of iteration

Level: Introductory

A complex number is a point, a quadratic function is a rule for moving it, and an orbit records repeated moves. Both the Mandelbrot set and the Julia sets come from these three ingredients.

Numbers with two coordinates

A complex number has the form z = x + yi, where x and y are real numbers and i2 = −1. Draw it at the point (x, y): the horizontal direction is the real axis, the vertical direction the imaginary axis. Complex numbers therefore give a convenient arithmetic for a two-dimensional plane. There is nothing approximate about the imaginary coordinate; the name is historical.

The modulus |z| is distance from the origin, and the argument is the angle measured counterclockwise from the positive real axis. The complex conjugate conj(z) = x − yi is its reflection across the real axis.

|x + yi| = √(x2 + y2)   ·   z = r(cos θ + i sin θ) = reiθ

Adding complex numbers adds their coordinates. Multiplying them multiplies their moduli and adds their arguments. Squaring therefore changes radius r into r2 and angle θ into 2θ. Points inside the unit circle move inward under squaring, while points outside move outward. Adding a constant then shifts the result. Repeated step after step, this competition between squaring and shifting decides which points move off to infinity and which do not, and so shapes the Julia sets and the Mandelbrot set.

Iterating z2 + c

Throughout this guide the map is the quadratic polynomial fc(z) = z2 + c. The complex number c is a parameter: choose it once and keep it fixed while following an orbit. Choose a starting point z0, apply the rule to obtain z1, then feed that result back in.

z0 → z1 = z02 + c → z2 = (z02 + c)2 + c → ⋯

The infinite sequence is the forward orbit. The notation fcn(z) means applying the function n times; it does not mean raising its output to the power n. For example, fc2(z) = (z2 + c)2 + c. The notation f∘n is sometimes used to emphasize composition.

Nothing random enters the rule. The same exact parameter and starting point always produce the same orbit. Yet nearby starting points can eventually behave very differently, because each new calculation acts on the previous result; the chapter on chaos works out an exact example. Cornell’s introduction to iterated maps develops this orbit viewpoint first in one real dimension.

For computation, write c = a + bi and expand the square. Both new coordinates must be computed from the old coordinates:

xn+1 = xn2 − yn2 + a
yn+1 = 2xnyn + b

As a concrete check, use z0 = 0 and c = i. The orbit begins 0 → i → −1 + i → −i → −1 + i. After the first two steps, it repeats a two-point cycle. This example will return when we discuss Misiurewicz parameters.

A point in the Mandelbrot picture selects an entire dynamical system. A point in a Julia picture selects one starting position inside that system. Both pictures use complex coordinates, but the coordinates play different roles. The Mandelbrot set is often called a “map of Julia sets” in this sense: each of its points indexes a Julia set, but the Julia sets are not pieces of it.

Why start the Mandelbrot orbit at zero?

The derivative of fc is 2z, which vanishes at exactly one finite point: z = 0. This is the critical point, and its image fc(0) = c is the critical value. Near a noncritical point, the map acts to first order as a rotation and scaling. At zero that linear approximation vanishes, and the quadratic folding becomes essential. In particular, opposite inputs z and −z have the same image.

A major theorem connects that special orbit to the whole picture: the quadratic filled Julia set is connected exactly when the orbit of zero is bounded. If that orbit escapes, the Julia set is a Cantor set: a “dust” of points with no isolated points, in which no two points are joined by a connected piece. The Julia chapter explains this dichotomy, and the Mandelbrot chapter turns it into a picture; see also Devaney’s explanation of the fundamental dichotomy.

Why an escape test works

An orbit escapes if its modulus tends to infinity. For an arbitrary fixed c, choose R = max(2, |c|). If an iterate has modulus r > R, the reverse triangle inequality gives

|z2 + c| ≥ |z|2 − |c| ≥ r2 − r = r(r − 1) > r.

Subsequent moduli grow by a factor at least as large as the first r − 1, which exceeds one. Growth therefore continues without bound. This proves a sufficient escape radius. Crossing it gives a conclusion about the entire future, even though the test examines only a finite prefix of the orbit.

For the Mandelbrot critical orbit, radius 2 suffices for every parameter. If |c| ≤ 2, the same estimate with r2 − 2 works whenever r > 2. If |c| > 2, the first image c already lies beyond 2, and the orbit does escape: |c2 + c| ≥ |c|2 − |c| > |c|, so the next point lies beyond the general radius max(2, |c|), and the preceding argument applies from there.

For example, at c = 1 the critical orbit begins 0 → 1 → 2 → 5. The value 2 is not yet beyond the radius, but 5 is, so three steps prove that this orbit escapes and that c = 1 lies outside the Mandelbrot set.

The inequality is strict. For c = −2 the critical orbit is 0 → −2 → 2 → 2, so reaching modulus 2 does not imply escape. And radius 2 is not a universal Julia escape test for arbitrary c: with c = −6, the point z = 3 is fixed despite having modulus greater than 2.

Failure to escape after a million steps is not, by itself, proof of boundedness. An orbit can stay close to a repelling or parabolic feature for a very long time before leaving. Mathematical membership means bounded forever; a finite escape-time image shows which sampled orbits have escaped so far.

Derivatives measure local stretching

Suppose two nearby points differ by a small displacement δ. An exact expansion shows

fc(z + δ) − fc(z) = 2zδ + δ2.

When δ is small, the first term dominates: one step multiplies the displacement by the derivative 2z. Its modulus stretches or shrinks the displacement, and its argument turns it. At the critical point the derivative is 0, and only the much smaller δ2 remains.

At a fixed point a, a point with fc(a) = a, this decides what nearby orbits do. The number λ = 2a is the fixed point’s multiplier. If |λ| < 1, every step shrinks the distance to a, and nearby points are attracted. If |λ| > 1, they are pushed away. For c = 0 the fixed points are 0 and 1: at 0 the multiplier is 0, and the orbit 0.1, 0.01, 0.0001, … rushes in; at 1 it is 2, and the orbit 1.1, 1.21, 1.4641, … moves away. When |λ| = 1 the first-order term no longer decides, and subtler things happen. The orbits chapter extends the multiplier to cycles and classifies all these cases.

A change of coordinates can reveal the same dynamics

Two formulas can describe equivalent motion in different coordinates. If an invertible map h satisfies h ∘ f = g ∘ h, then applying h to an orbit of f produces an orbit of g. This relationship is called a conjugacy. Its strength depends on the allowed coordinate change: continuous, differentiable, holomorphic, and quasiconformal conjugacies preserve different amounts of geometry.

For example, any quadratic polynomial q(z) = az2 + bz + d, with a ≠ 0, becomes the standard quadratic family after the affine substitution w = az + b/2. Direct expansion gives

w ↦ w2 + C,   where   C = ad + b/2 − b2/4.

This is why studying z2 + c is so general: it covers every complex quadratic polynomial up to a shift and nonzero scaling of coordinates. Renormalization later applies a subtler version of this idea to a return map on a small region, explaining why quadratic behavior reappears within much larger orbits.

Key ideas

  • A complex number is a point of the plane. Multiplying multiplies distances from 0 and adds angles, so squaring squares the distance and doubles the angle.
  • The atlas iterates fc(z) = z2 + c: c stays fixed while z moves, and the points visited form the orbit.
  • A Julia picture fixes c and varies the starting point; a Mandelbrot picture varies c and always starts at the critical point 0.
  • Once an iterate is farther from 0 than max(2, |c|), the orbit escapes; for the orbit of 0, farther than 2 is enough. An orbit that has not escaped after many steps may still escape later.
  • Near a fixed point a, one step multiplies small distances by about |2a|; the multiplier λ = 2a decides whether nearby points are attracted (|λ| < 1) or repelled (|λ| > 1).
  • Every quadratic polynomial becomes z2 + c after a change of coordinates.

Check yourself

  1. Compute (1 + 2i)2. How do its distance from 0 and its angle compare with those of 1 + 2i?

    (1 + 2i)2 = 1 + 4i + 4i2 = −3 + 4i. The distance of 1 + 2i from 0 is √5; that of −3 + 4i is 5 = (√5)2. The angle of 1 + 2i is about 63.4°, and that of −3 + 4i is about 126.9°, twice as large.

  2. Take c = −1 and start at z0 = 0. Write down the first five points of the orbit. What do you notice?

    0, −1, 0, −1, 0. The orbit repeats every two steps: it is a cycle of period 2 that contains 0, so its multiplier is 2 · 0 · 2 · (−1) = 0 and it is superattracting.

  3. Is c = 1 + i in the Mandelbrot set? Follow the orbit of 0 until you can decide.

    No. The orbit begins 0, 1 + i, then (1 + i)2 + 1 + i = 2i + 1 + i = 1 + 3i. Its distance from 0 is √10 ≈ 3.16, more than 2, so the escape argument shows that the orbit escapes.

  4. Why is “escapes once |z| > 2” not a valid test for every Julia picture? Use c = −6.

    For c = −6 the point 3 is fixed, since 32 − 6 = 3, so its orbit never escapes although |3| > 2. The general escape radius is max(2, |c|), here 6. The radius 2 works for every Julia picture with |c| ≤ 2, and for the orbit of 0 in every Mandelbrot picture.

  5. Find the fixed points of z ↦ z2 − 2 and their multipliers. Do they attract or repel?

    A fixed point solves z2 − 2 = z, that is (z − 2)(z + 1) = 0, so the fixed points are 2 and −1. Their multipliers 2z are 4 and −2. Both have modulus greater than 1, so both repel.

  6. Which z2 + c is z ↦ 2z2 + 1 in disguise?

    Here a = 2, b = 0 and d = 1, so w = 2z and C = ad = 2. Indeed 2(2z2 + 1) = (2z)2 + 2, so w ↦ w2 + 2. Since the orbit 0, 2, 6, 38, … escapes, 2 is not in the Mandelbrot set, and the Julia set of the original map is a Cantor set too.

Sources and further reading

The worked arithmetic, escape argument, and coordinate substitution above are self-contained derivations. These sources provide the broader mathematical framework:

  • Chris Lipa, Cornell Math Explorers’ Club — One-Dimensional Maps — iteration, fixed points, cobweb diagrams and periodic orbits.
  • Robert Devaney — The fundamental dichotomy — the role of the critical orbit in quadratic connectedness.
  • John Milnor — Dynamics in One Complex Variable, introductory lectures — rigorous foundations and local dynamics; later expanded into the book of the same name (third edition, Princeton University Press, 2006).
