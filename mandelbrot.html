The Mandelbrot set

Level: IntroductoryBuilds on Julia sets

The Mandelbrot set is a map of quadratic dynamics. Every point chooses a different equation; the set collects exactly those choices for which the critical orbit stays bounded forever.

A precise definition

Choose a complex parameter c. Start at z0 = 0 and repeatedly calculate zn+1 = zn2 + c. The Mandelbrot set, written M, is the collection of parameters for which the resulting sequence is bounded:

M = {c ∈ ℂ : there is a finite B such that |fcn(0)| ≤ B for every n ≥ 0}.

“Bounded” does not mean converging to one value. A bounded orbit might approach a cycle, eventually repeat exactly, rotate without settling, or behave in a more complicated way. Membership asks only whether the orbit remains in some finite disk. In this family, an unbounded orbit necessarily escapes to infinity.

The tested starting point is zero because it is the unique finite critical point of the quadratic map, and the orbit of the critical point controls the whole dynamics. A closely related convention starts at z0 = c; this drops the initial zero and gives exactly the same boundedness decision.

Four parameters you can check by hand

The four critical orbits of the orbits chapter settle membership at once. For c = 0 the orbit stays at 0, for c = −1 it alternates between 0 and −1, and for c = −2 it runs 0, −2, 2, 2, …: all three are bounded, so these parameters lie in M. For c = 1 the orbit 0, 1, 2, 5, 26, … escapes, so 1 lies outside.

The example c = −2 shows that membership does not require attraction. The orbit lands exactly on the fixed point 2, whose multiplier 4 makes it repelling; it is bounded nonetheless. Such a parameter is a Misiurewicz parameter, and −2 is the leftmost point of the Mandelbrot set.

A map of connected Julia sets

For a fixed parameter, the filled Julia set Kc contains every starting point whose orbit stays bounded, and its boundary is the Julia set Jc. The quadratic dichotomy says

c ∈ M ⇔ Kc is connected ⇔ Jc is connected.

Outside M, the quadratic Julia set is a Cantor set: uncountably many points, totally disconnected, with no isolated points. Inside or on the boundary of M, it is connected, though its geometry varies enormously. This makes the Mandelbrot set the connectedness locus of the quadratic family. Cornell’s Mandelbrot lesson explains this interpretation.

Membership is a statement about the orbit of 0 alone. Even for c = 0, the starting point 2 escapes: 2, 4, 16, …. What c ∈ M guarantees is that the bounded starting points form one connected piece.

The main cardioid and the bulbs

The large central region is the main cardioid; the name means “heart-shaped.” It consists exactly of the parameters whose map has an attracting fixed point. If the fixed point has multiplier λ, then

c = λ/2 − λ2/4, |λ| < 1,

and letting λ run once around the unit circle traces the cardioid’s boundary. At λ = 0 the parameter is the center c = 0; at λ = 1 it is the cusp c = 1/4; at λ = −1 it is c = −3/4, where the large round bulb on the left is attached. That bulb is the period-two component: the parameters with an attracting cycle of two points form exactly the disk |c + 1| < 1/4, centered at −1. Both formulas take only a few lines to derive; the periodicity chapter does it under the cardioid and the period-two disk.

The other bulbs have other periods. The parameters with a finite attracting cycle form an open set, and each of its connected pieces is a hyperbolic component; the period of the attracting cycle is constant throughout it. Its center is the one parameter where the critical point itself is periodic. Around the main cardioid, the bulbs are arranged by rational numbers: the bulb attached where λ = e2πip/q, with p/q a fraction in lowest terms between 0 and 1, has period q. Secondary bulbs repeat this organization around their parents. Apart from the period-two disk, the bulbs are not in general exact circles.

A limb is a bulb together with everything attached beyond it. A wake is the region of the parameter plane cut off by the two external rays that land at the bulb’s root. The periodicity chapter develops all of this.

The fixed points in these formulas belong to the maps, not to the Mandelbrot set. Nothing is iterated in the parameter plane: each point c stands for its own map and never moves, so the set has no fixed points of its own. What it records are the fixed points of the maps. Each map has two (the structure of the Julia set), and only one of them can attract; it is called α, and the other β. The λ above is the multiplier 2α: the main cardioid is where α attracts, its edge is where |2α| = 1, and the p/q bulb is attached where 2α = e2πip/q. In the Julia sets of that bulb’s limb, q arms meet at α (rotation numbers), like the three lobes of Douady’s rabbit. Some boundary points of the set copy the look of α and β as well: where the orbit of 0 lands on β, the set ends in a tip, and where it lands on α, its branches meet (tips and branch points).

Interior, boundary, and exterior

An interior point has a small disk around it contained in M. An exterior point lies outside M and has an escaping critical orbit. A boundary point belongs to M, but every disk around it also contains exterior parameters. The boundary is where arbitrarily small parameter changes can cross from bounded critical dynamics to escape.

The main cardioid and the open bulbs are easy to recognize as interior regions. The boundary includes their edges, branching structures, tips, and limits of ever smaller features. Some prominent features are minibrots, small topological copies of the whole set. Others are parabolic and Misiurewicz points, where orbits satisfy special relations.

The set is compact: it is closed and lies inside |c| ≤ 2. It is symmetric under reflection across the real axis, because conjugating both the parameter and every orbit point preserves the recurrence. Unlike a Julia set, it has no half-turn symmetry: a Julia set has one because the map sends z and −z to the same point, but c and −c are two different maps. The left tip −2 belongs to the set, while 2 does not: its orbit 0 → 2 → 6 escapes. Its intersection with the real axis is exactly the interval [−2, 1/4]. Along that interval lie the real quadratic maps of the chapter on chaos, with their period-doubling cascade and chaotic parameters.

Where Julia sets change

Move c around inside the main cardioid, and the Julia set deforms but remains a closed curve. Move it inside the period-two disk, and it remains a pinched chain of loops like the basilica. Move it outside M, and it remains dust. The type of the Julia set changes only when c crosses the boundary of M.

This can be made precise. Away from the boundary of M, the Julia set depends continuously on the parameter, and the Julia sets of nearby parameters are deformations of one another; inside one component of the interior of M, they all have the same shape, and the maps act on them in the same way (Lyubich’s book, Theorem 36.2). At every point of the boundary this stability fails: arbitrarily close to it there are parameters whose Julia sets are of a different kind, such as Cantor sets just outside M. In McMullen’s formulation, the boundary of the Mandelbrot set is exactly the set of parameters that are not “J-stable” (McMullen, Complex Dynamics and Renormalization, Theorems 4.2 and 4.6), building on the work of Mañé, Sad and Sullivan (1983). The boundary of M is therefore the bifurcation locus of the quadratic family: the parameters where an arbitrarily small change alters the Julia set, and the dynamics on it, qualitatively. Every parameter with a neutral cycle, parabolic or irrational, lies on it (McMullen, Theorem 4.8). The Mandelbrot set is a map of Julia sets in this sharper sense too: its boundary marks every place where they change.

Why the Mandelbrot set is connected

The Mandelbrot set itself is connected, as Adrien Douady and John Hubbard proved in 1982 (Douady and Hubbard, 1982). The idea of the proof can be explained with the escape rate of the critical orbit. Outside M, the numbers log⁠|⁠zn⁠| roughly double with every step, so the limit

g(c) = limn→∞ log|zn| / 2n

exists. It is positive outside M and set to 0 on M; in electrostatics it would be the electric potential around a charged plate shaped like M. The curves on which it is constant are called equipotentials. Douady and Hubbard constructed a coordinate that maps the outside of M one-to-one and without distortion of angles onto the outside of the unit disk, carrying the equipotentials to circles. Each equipotential is therefore a simple closed curve, and the region inside it is a closed topological disk. These regions are nested, and M is what remains in all of them. What remains of a nested sequence of closed disks is always connected, so M is connected. The chapter on external rays describes this coordinate and the corresponding one in the dynamical plane, and Kathryn Lindsey’s introductory exposition presents the proof.

The boundaries between the colored bands in escape-time pictures approximate these equipotentials: all pixels in one band escaped after the same number of steps. Seemingly isolated minibrots in an image are not separate islands of the set: the parts of M that connect them to the rest are thinner than the pixels. Connectedness means that M cannot be split into two separated pieces. Whether any two of its points can be joined by a curve inside the set, a stronger property called path-connectedness, is not known; it would follow from the MLC conjecture below.

Dimension and area

The boundary of the Mandelbrot set has no interior, yet Mitsuhiro Shishikura proved that it has Hausdorff dimension 2, the largest possible in the plane (Shishikura, 1998). Whether it also has positive area is open, and so is the exact area of M itself: it is at least 7π/16 ≈ 1.3744, pixel counts estimate about 1.50659, and floating-point computations that cover the plane with squares place it between about 1.506 and 1.531. The chapter on area, dimension and famous numbers explains these numbers, the dimensions of Julia sets, and Julia sets of positive area.

What remains open

Three basic questions about the Mandelbrot set are open as of October 2026: whether it is locally connected (the MLC conjecture), whether the hyperbolic parameters, those with an attracting cycle or an escaping critical orbit, are dense (the density of hyperbolicity), and whether its boundary has positive area. MLC is known at every parameter that is not infinitely renormalizable and at many that are, including the Feigenbaum point (2026), and it would imply the density of hyperbolicity, which is proved for real parameters. The chapter on open questions states them precisely, explains the methods behind the progress, and lists what is known.

What the colored image does and does not show

An escape-time picture samples parameters on a grid and follows each critical orbit until it crosses the escape radius 2 or reaches an iteration limit. In exact arithmetic a colored pixel would prove that its sample point lies outside M; the computer’s rounding makes this a very reliable indication rather than a proof. A dark pixel only says that the orbit had not escaped yet. Palettes, smooth coloring and distance shading change the texture of a picture without changing the set. The chapter on computing the pictures explains the methods and what each of them proves, the gallery’s image-method notes explain how the atlas’s plates were made, and the guided tour connects spirals, valleys and fine branching with the dynamics behind them.

Key ideas

  • The Mandelbrot set M is the set of parameters c for which the orbit of 0 under z2 + c stays bounded.
  • It is also the set of c whose Julia set is connected; outside it, Julia sets are dust.
  • The main cardioid holds the parameters with an attracting fixed point; the bulbs hold those with attracting cycles of other periods.
  • Inside each component of the interior, the Julia sets keep their shape; the boundary of M is exactly where they change.
  • M is connected, because it is the intersection of nested closed disks bounded by equipotentials. Whether it is locally connected (MLC) is still open.

Check yourself

  1. Is c = −1 + 0.1i in the Mandelbrot set?

    Yes. |c + 1| = 0.1 < 1/4, so c lies in the period-two disk: the map has an attracting cycle of period two, the orbit of 0 is attracted to it, and in particular it is bounded.

  2. Show that c = 0.3 is not in the Mandelbrot set. After how many steps does the orbit of 0 pass 2?

    The Mandelbrot set meets the real axis in [−2, 1/4], and 0.3 > 1/4. Computing confirms it: the orbit 0, 0.3, 0.39, 0.4521, 0.5044, 0.5544, … creeps upward, slowly at first, and z12 ≈ 2.19 is the first value beyond 2. From there the escape argument shows that the orbit escapes.

  3. Which parameter on the edge of the main cardioid has a fixed point with multiplier i?

    c = i/2 − i2/4 = 1/4 + i/2. It is the point where the bulb of period 4 is attached, since i = e2πi·1/4.

  4. Why is the Mandelbrot set symmetric under reflection in the real axis?

    If c is replaced by its complex conjugate, every point of the orbit of 0 is replaced by its conjugate, because conjugation respects squaring and addition. Conjugate numbers have the same modulus, so one orbit is bounded exactly when the other is.

  5. The Julia sets of c = −1 and c = −1.1 look alike. Why should they?

    Both parameters lie in the period-two disk |c + 1| < 1/4, one component of the interior of M. Within such a component the Julia sets are deformations of one another, so both are pinched chains of loops like the basilica.

  6. An escape-time picture shows a tiny dark island with no visible connection to the rest of the set. Does this contradict the connectedness of M?

    No. If the island belongs to M, whatever connects it to the rest is thinner than the pixels, so the sampling misses it; a dark pixel may also just be a point whose orbit had not escaped within the iteration limit. Connectedness is a theorem; the picture is a finite sample.
